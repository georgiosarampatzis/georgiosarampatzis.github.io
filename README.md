# Georgios Arampatzis — Academic Portfolio

A responsive one-page academic portfolio designed for GitHub Pages, with dedicated sections for NLP, Business Intelligence and Information Retrieval.

## What to replace

1. Replace `assets/profile-placeholder.svg` with your photo.
2. Replace every `href="#"` with the correct link.
3. Replace `your-email@example.com` with your real email.
4. Add your CV as `assets/Georgios-Arampatzis-CV.pdf` and update the CV button.
5. Add or remove publications, projects and posts directly in `index.html`.

## Publish with GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/root`.
6. Your site will appear at `https://YOUR-USERNAME.github.io`.

## Preview locally

Open `index.html` directly in a browser, or run a small local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
